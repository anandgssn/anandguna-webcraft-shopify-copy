## How to Replace
1. Generate replacement with Manus/Veo/similar AI tool
2. Drop into the same path in `public/` with the same filename
3. No code changes needed
4. For videos: MP4, ~480-1080p, 5-15 seconds, looping
5. For stacked photos: JPG, ~400x400, event/gathering scenes
6. For article backgrounds: PNG, ~415x558, abstract geometric patterns
7. For studio: WebP or JPG, ~1750x977, modern office interior
8. For favicons: PNG, exact sizes listed above
